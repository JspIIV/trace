Trace. copies flagged, on evidence
GenLayer Asimov

A work is flagged as a copy only when an earlier, dated source shows it to be one.

Trace does not certify originality, because on the open web nobody can prove a negative about themselves from pages they may control. It does the one thing evidence can settle: anyone registers a work, and anyone can challenge it by naming an earlier public page it is said to be copied from. The contract fetches both pages and a GenLayer round flags the work only if it reproduces the earlier page and the pages show that page came first. A challenge that shows no copy — an unrelated page or an unreadable one — changes nothing and leaves the work open, so a clean record can never be manufactured, only left standing.
